# Marketing and Product Performance Analysis

## Project Overview
In this project, I analyzed a marketing and product performance dataset to understand how different factors affect product success. The main goal was to see how things like marketing spend, pricing, discounts, ratings, and supply chain efficiency influence how well a product performs.

I also built a machine learning model to predict the success percentage of a product based on these features.

---

## Dataset
I used a dataset from Kaggle:

https://www.kaggle.com/datasets/imranalishahh/marketing-and-product-performance-dataset

The dataset contains 500 rows and 15 columns with details about products, sales, marketing spend, and performance.

---

## Research Questions
The analysis is based on the following questions:

1. How does marketing spend affect product success?
2. What is the relationship between price, discount, and sales?
3. Which product categories perform the best?
4. How do ratings and number of reviews impact success?
5. Does supply chain efficiency affect sales?
6. How do market trends and seasonality influence success?
7. Which machine learning model predicts success the best?

---

## Project Files
This repository includes:

- 7 Jupyter notebooks (one for each research question)
- CSV files containing tables/results
- PDF files of graphs and visualizations
